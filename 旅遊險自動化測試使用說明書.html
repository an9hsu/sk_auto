一、先搞懂幾個名詞

自動化測試，就是把「人手動點網頁、用眼睛檢查」寫成劇本，讓電腦照劇本一鍵重跑。網站每次更新後跑一次，就知道有沒有東西壞掉。

名詞白話解釋
測試（TC，Test Case）一段劇本，例如「選香港、選日期、按下一步，確認保費有出來」。
通過（passed）劇本照走完，畫面都跟預期一樣。
失敗（failed／error）某一步跟預期不一樣，或網頁打不開。
終端機輸入指令的文字視窗。Mac 是「終端機」App，Windows 是「PowerShell」。本說明的指令都在這裡輸入，打完按 Enter。
指令打在終端機裡、叫電腦做事的一行字，例如 pytest --env=prod -m travel。
專案資料夾存放這套測試的資料夾（sk_auto）。所有指令都要在這個資料夾裡執行。
虛擬環境（.venv）這個專案專用的工具箱，跟電腦上其他程式互不干擾。每次打開終端機都要先「啟用」它。
Python／pytest／Selenium這套測試用到的工具：Python 是程式語言，pytest 負責執行測試，Selenium 負責操作瀏覽器。只要裝好，不用懂它們怎麼寫。
headless／headedheadless：瀏覽器在背景跑，看不到視窗（預設）。headed：會開出視窗，看得到電腦在點什麼。
Allure 報表測完後產生的網頁報告，用瀏覽器打開就能看每個測試的結果和截圖。

二、它幫你檢查了什麼

目前有 10 個測試，全部在旅遊險正式網站上跑，都停在繳費前，不會真的投保或付錢。

#檢查什麼（白話）走到哪一頁為止
1多人投保一路填到「會員登入」，帳號有自動帶入（不會按登入）會員登入
2首頁每個「熱門地點」都點得到首頁
3多人投保時，月曆最早只能選 3 天後出發首頁
4選 3 天的行程，確認框的地點、日期、天數正確，且有算出保費保費試算
5同上，換成 30 天、跨月份的行程保費試算
6只選 2 天 → 網站會提醒「保險期間至少 3日」首頁
7什麼都沒填就按「下一步」→ 會被擋下首頁
8月曆沒選日期就按「確定」→ 提醒「請選擇出發與結束日期」首頁
9每個保險方案都有保費且不同；切換方案會跟著改保費試算
10聲明事項沒看完不能勾；沒勾同意就按下一步會被擋下保費試算

三、第一次安裝

只要做一次。跟著下面 5 步做完，之後每次只要「啟用環境 → 跑指令」。遇到看不懂的錯誤訊息，先看第七節「遇到問題」。

  1. 安裝 4 個軟體

    都是一路按「下一步」就能裝好。

    Python 3.12執行測試。python.org/downloads，選 3.12.x；Windows 安裝時一定要勾「Add python.exe to PATH」
    Google Chrome測試用的瀏覽器。google.com/chrome
    Git下載專案。git-scm.com/downloads，Mac 通常已內建
    Node.js產生報表。nodejs.org，選 LTS 版

  2. 確認裝好了

    打開終端機輸入下面指令，有出現版本號碼就代表成功（應顯示 Python 3.12.x）。

    Mac 終端機
    python3.12 --version
node --version
    Windows PowerShell
    py -3.12 --version
node --version

  3. 下載專案

    第二行是「進入專案資料夾」，之後所有指令都要在這個資料夾裡執行。

    終端機
    git clone https://github.com/an9hsu/sk_auto.git
cd sk_auto

  4. 建立並啟用虛擬環境、安裝工具

    一行一行輸入。成功啟用後，終端機每一行最前面會出現 (.venv)。

    Mac 終端機
    python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
    Windows PowerShell
    py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
    Windows 出現「已停用指令碼執行」？

    先輸入一次 Set-ExecutionPolicy -Scope CurrentUser RemoteSigned 再重試。

  5. 安裝報表工具

    第二行會顯示版本，看到 3.20.1 就完成了。

    終端機
    npm install
npx allure --version
小提醒

瀏覽器的「驅動程式」不用自己裝，第一次跑測試時會自動下載，所以第一次會比較久。

四、設定個人資料

只要做一次。測試要填身分證、生日、會員帳號。這些是個資，只存在你自己電腦的兩個檔案裡，不會上傳。

  1. 複製範本

    在專案資料夾輸入指令。注意新檔名前面多一個點 .。

    Mac 終端機
    cp configs/account_prod.yml.sample configs/.account_prod.yml
    Windows PowerShell
    copy configs\account_prod.yml.sample configs\.account_prod.yml

  2. 填入真實資料

    用記事本或 VS Code 打開 configs/.account_prod.yml，把假資料換成真的。生日用西元、前後要加雙引號，例如 "1990/01/01"。

  3. 設定會員密碼

    同樣把 .env.sample 複製成 .env，打開後在 TRAVEL_MEMBER_PWD= 後面填密碼。

找不到「.」開頭的檔案？

Mac 的 Finder 預設看不到它們，按 Cmd + Shift + . 就會顯示。

五、開始跑測試

每次要跑測試，都是同樣 3 步：打開終端機 → 進專案資料夾並啟用環境 → 輸入指令。

  1. 進專案資料夾、啟用環境

    Mac 終端機
    cd sk_auto
source .venv/bin/activate
    Windows PowerShell
    cd sk_auto
.venv\Scripts\Activate.ps1

  2. 選一行指令輸入

    看到 (.venv) 後，依照想做的事選一行。

    跑全部測試 最常用
    背景執行，看不到視窗
    pytest --env=prod -m travel
    跑全部，並開視窗看電腦怎麼點
    headed
    pytest --env=prod -m travel --headed
    只跑某一個測試
    -k 後面接測試名稱的一部分
    pytest --env=prod -k reach_member_login --headed
    改用 Edge 瀏覽器
    Edge
    pytest --env=prod -m travel --browser-name=edge

    指令裡各部分的意思：

    --env=prod
    測正式網站，一定要加
    -m travel
    只跑旅遊險
    --headed
    開視窗
跑的時候

不要關掉終端機，也不要去點彈出來的瀏覽器視窗。

六、看結果

跑完後終端機最後一行會告訴你幾個通過、幾個失敗。

範例：10 個全部通過
==== 10 passed in 245.12s ====
passed

通過，沒問題。

failed

檢查沒過：網站行為跟預期不同，可能是網站的 bug。

error

測試本身沒跑起來，常見原因是網站打不開或在維護。

skipped

這次跳過沒跑。

失敗時的截圖

只要有測試失敗，就會自動截圖存在 test-results/screenshots/ 資料夾，檔名就是測試名稱。打開就知道卡在哪個畫面。

網頁報表（推薦）

跑完測試後輸入下面指令，瀏覽器會開出繁中報表。

終端機
npx allure generate allure-results --open

報表裡可以看到：

  • 每個測試通過或失敗、花了多久
  • 失敗的測試停在哪一步，以及當下的截圖和網址
  • 歷次執行的通過率趨勢

看完回到終端機按 Ctrl + C 結束。想給別人看，把 allure-report/awesome/index.html 這一個檔案寄出去就好，對方雙擊就能打開。

七、遇到問題

大部分問題都是「沒啟用環境」或「不在專案資料夾」。先對下表，都不是的話把截圖和終端機最後幾行一起交給維護的工程師。

看到的狀況怎麼解決
pytest: command not found 或「不是內部或外部命令」沒啟用環境。先輸入第五節的啟用指令，看到 (.venv) 再跑
--env 必填指令忘了加 --env=prod
Env yaml not found不在專案資料夾，先輸入 cd sk_auto
Account yaml not found還沒建個資檔，看第四節
第一次跑卡很久正在自動下載瀏覽器驅動程式，等一下就好
npm 或 npx: command not foundNode.js 沒裝好；裝完要關掉終端機重開
全部測試一起失敗，出現 TimeoutException 或截圖是維護公告旅遊險網站在系統維護，等維護結束再跑
偶爾一個失敗，重跑又過了網站剛好慢，可以忽略；常常發生就回報工程師
同一個測試每次都失敗可能網站改版或有 bug，把截圖和 Allure 報表交給工程師

八、一定要遵守的規則

這是正式網站，也會用到真實個資，以下三條請務必遵守。

  1. 不要改測試程式讓它走到「繳費」這是正式網站，所有測試最多停在會員登入前。
  2. 個資只放在 configs/.account_prod.yml 和 .env不要寫進其他檔案，也不要上傳或寄給別人。
  3. 寄報表前先看一下截圖失敗截圖可能拍到已填入的身分證或生日。
